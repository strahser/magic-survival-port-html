## Что уже внедрено (по твоим двум ТЗ)

1. **Шутер-фаза**: `G.mode='shooter'`, корабль `▲`, цель 7000, warp 1.2, авто-огонь с 60%, мид-элита на 50%, паттерны straight/sine/dive/hover (brute-sine), прогресс-бар.
2. **Босс-арена**: граница r=380 (игрока не выталкивает), кап миньонов ≤12, цветной `[[Ω]]`, зачистка + золотые лучи + сундук после смерти.
3. **Prep-фаза**: `closeReward` → `G.prep=2.4` → «ПРИГОТОВЬСЯ К ГИПЕРПРЫЖКУ», нарастающие лучи, враги спавнятся (travT 0.9) → `startShooter`.
4. **Синергии**: цветная карточка при активации (2.8с), цветные компоненты в карточках/дереве.

## Симуляция полного цикла (headless Chrome, реальный runtime, богомод)

Прогон сцены 1 до конца: волны → босс → сундук → выбор → prep → прыжок → сцена 2.

| Метрика | Значение | Комментарий |
|---|---|---|
| Босс 1 заспавнен | t=72с (70 + 2.2s warn) | штатно |
| kill босса | stage 0→1, сундук boss:true, beamFx=2 | штатно |
| Подбор сундука → reward → closeReward | pendingShooter true → prep 2.4 | штатно |
| Prep → startShooter | mode play→shooter | штатно (FP-грань: +1 кадр, не заметно) |
| Мид-элита | на dist≥3500 (50%), brute×3 hover | штатно (проверено отдельно) |
| Авто-огонь | с dist≥4200 (60%) | штатно |
| **Длительность прыжка** | **31.1с** (goal 7000 / 230 px/s) | как задумано ~30с |
| endShooter | mode→play, игрок в центр сцены | штатно |
| Сцена 2 | директор снова спавнит (enemies 8+) | штатно |
| **Ошибок в консоли** | **0** | рендер prep/шутер чист |

## Вопросы баланса (на твоё усмотрение, скажешь — подкручу)

1. **Авто-огонь стартует на 60%** (≈18-я секунда прыжка): ~половина полёта корабль стреляет только если взяты семена-лучи, а враги льют пули. Не скучновато ли? Варианты: включить с 45-50%, или усилить стартовый ствол `▲` (сейчас одиночная пуля 20×dmg, pierce 2 — против пары ховеров на 3-й секунде уже тесно).
2. **Плотность волн**: travT 2.2 → 1.5 на 60%. За прыжок ~18-22 врага. Сложность сцены 1 ощущается лёгкой (урон 6, стрельба 8/10, e.dmg*.8 в пулях: 6-10). Хочешь — добавлю нарастание урона/здоровья от `G.stage` в спавн (сейчас hp без stage-множителя).
3. **Стрелки-ховеры** целятся прицельно (atan2): на 70% полёта пули идут ровно в игрока. Ок для нормала; для «жёстче» позже можно добавить паттерн-залп.
4. **Prep-плотность**: 2.4с × travT 0.9 ≈ 2-3 врага «заряжаются» до прыжкового спавна — норм, но при goal 7000 они делают первую треть полёта плотнее. Оставляем?
5. После `endShooter` оверлей/баннер «СЦЕНА N — ЖЁСТЧЕ» есть; вопрос: нужен ли ещё и отчёт за прыжок (убито/урон за полёт) в лог?

## Следующие кандидаты
