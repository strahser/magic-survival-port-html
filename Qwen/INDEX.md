# Qwen/ — очереди отчётов для отправки облачному ИИ

**Назначение:** единое место, из которого понятно, ЧТО и КОГДА отправлять Qwen
(chat.qwen.ai через Агента-3/вставку в чат) и что уже сделано по его ответам.

## Структура

```
Qwen/
  INDEX.md                      ← этот файл (единственный источник статусов)
  <ГГГГ-ММ-ДД>/                ← папка по дате
    <ЧЧ-ММ>_<тема>_статус-<X>.md  ← отчёт; ЧЧ-ММ = время создания/отправки
```

Правило имени: `ЧЧ-ММ_тема_статус-новый.md`. При смене статуса файл ПЕРЕИМЕНОВЫВАЕТСЯ
(статус в имени остаётся актуальным), строка в INDEX обновляется.

## Статусы (жизненный цикл отчёта)

| Статус | Что значит | Действие |
|---|---|---|
| `новый` | готов к отправке | скопировать текст в чат Qwen |
| `отправлен` | текст ушёл в чат Qwen | ждать ответ |
| `ответ-получен` | ответ сохранён рядом (файл `..._ответ.md`) | применить/проанализировать |
| `применён` | правки по ответу внесены в код (указать коммит) | закрыт |
| `архив` | не актуален / заменён | оставить в Data\ или удалить |

## Порядок работы

1. Новый отчёт кладётся в `Qwen\<дата>\` с именем `ЧЧ-ММ_тема_статус-новый.md`, строка добавляется в INDEX.
2. Отправка: текст файла → чат Qwen (Агент-3 или вручную) → статус `отправлен`, имя файла переименуется.
3. Ответ Qwen сохраняется рядом: `ЧЧ-ММ_тема_статус-ответ-получен_ответ.md` + статус самого отчёта.
4. Правки применяются в код → статус `применён` + коммит в INDEX.
5. INDEX.md обновляется при КАЖДОМ изменении статуса; коммит: `docs: qwen <статус> <тема>`.
